How does code estimate a bend?

For a finger, the program uses three landmark points. Two vectors meet at the middle joint.

θ = cos⁻¹ ( u · v / |u| |v| )

A straighter finger is near 180°. The code maps a chosen straight-to-curled range to a control value. It is an estimate from the camera, not a real joint-angle measurement.

What the numbers mean

21 pointsMediaPipe hand landmarks
5 channelsThumb, index, middle, ring, pinky
0 → 90Open-to-curled command values from Python
25% smoothingArduino eases toward each new target

The serial bridge sends packets like <45,90,90,85,70> at 115,200 baud.

Safety layer

In the browser demo: a raised-middle-finger pose or sudden wrist jerk turns the check red and holds the robot at its last safe pose. The hand meters still show the unfiltered estimates.

Science fair measurements

The recorder collects 100 detected-hand results with processing delay, frame rate, finger-curl estimates, camera distance, and room-light input. Change one condition at a time and compare your own trials.

Important distinction: The browser safety gate and the Python/Arduino motor path are separate. The Python motor path does not currently include that same gesture/jerk block. The web pickup is simulated; only the optional maker build moves physical servos.
